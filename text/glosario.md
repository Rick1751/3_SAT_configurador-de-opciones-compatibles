# Glosario

- **SAT:** problema de satisfacer una fórmula booleana.
- **CNF:** conjunción de cláusulas, cada una disyunción de literales.
- **3-SAT:** CNF con tres posiciones por cláusula.
- **2-SAT:** CNF de dos literales, resoluble en tiempo polinomial.
- **Literal:** variable positiva o negada.
- **P, NP:** clases de problemas resolubles o verificables en tiempo polinomial.
- **NP-completo:** problemas de NP a los que se reduce todo problema de NP.
- **Reducción:** transformación que preserva la respuesta.
- **Certificado:** asignación que permite verificar SAT.
- **Cook–Levin:** teorema que prueba que SAT es NP-completo.
